# scripts

Репозиторий вспомогательных скриптов.

## amnezia.sh

Скрипт для подготовки сервера под VPN:

- задаёт часовой пояс;
- настраивает автоматическое обновление системы;
- настраивает параметры ядра для маршрутизации;
- запрещает вход по SSH по паролю и под пользователем `root`;
- закрывает все входящие соединения, кроме SSH, и разрешает
  транзитные соединения;
- устанавливает Docker и Docker Compose;
- создаёт суперпользователя и показывает его приватный ключ в виде QR-кода.

Скрипт идемпотентен — можно запускать неограниченное количество раз.

ВНИМАНИЕ! Чтобы порты устанавливаемых на сервер сервисов были доступны извне, они
должны запускаться через Docker.

### Требования

- Debian 13 и выше;
- запуск от имени `root`.

### Запуск

```bash
bash <(wget -qO- https://raw.githubusercontent.com/radimih/scripts/main/amnezia.sh)
```

Скрипт в процессе работы запросит имя создаваемого суперпользователя.
