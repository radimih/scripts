# scripts

Репозиторий вспомогательных скриптов.

## vpn.sh

Скрипт для подготовки сервера под VPN:

- задаёт часовой пояс и включает синхронизацию времени;
- задаёт локаль: `en_US.UTF-8` по умолчанию, `ru_RU.UTF-8` — для форматов даты и
  времени, чисел, денежных единиц и т.д.;
- настраивает сообщение при логине в систему;
- настраивает журнал systemd (journald);
- настраивает автоматическое обновление и перезагрузку системы;
- настраивает параметры ядра для маршрутизации;
- запрещает вход по SSH по паролю и под пользователем `root`;
- закрывает все входящие соединения, кроме SSH, и разрешает
  транзитные соединения;
- устанавливает Docker и Docker Compose;
- создаёт суперпользователя и показывает его приватный ключ в виде QR-кода.

Скрипт идемпотентен — можно запускать неограниченное количество раз.

ВНИМАНИЕ! Чтобы порты устанавливаемых на сервер сервисов были доступны извне, они
должны запускаться через Docker.

### Требования

- Debian 13 и выше;
- запуск от имени `root`.

### Запуск

```bash
bash <(wget -qO- https://raw.githubusercontent.com/radimih/scripts/main/vpn.sh)
```

Скрипт в процессе работы запросит имя создаваемого суперпользователя. Это должен
быть уже существующий *обычный* пользователь системы, или новый пользователь.
