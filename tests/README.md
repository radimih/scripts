# Тесты скриптов

Проверка скриптов в среде Debian 13 (trixie) без риска для рабочей машины:
тесты выполняются в одноразовом контейнере.

## Запуск

```bash
tests/run-tests.sh <script>
```

`<script>` — имя скрипта в корне репозитория без расширения `.sh`. Аргументы
после имени передаются в bats, например:

```bash
tests/run-tests.sh <script> --filter 'missing'
```

Список скриптов, для которых есть тесты:

```bash
tests/run-tests.sh --help
```

## Структура

- `debian.Dockerfile` — базовый образ `scripts-test:debian`: Debian 13 и
  инструменты, общие для любых тестов (`bats`, `shellcheck`).
- `<script>.Dockerfile` — образ `scripts-test:<script>` для конкретного скрипта;
  наследуется от базового (`ARG BASE_IMAGE`) и добавляет только те пакеты,
  которые нужны этому скрипту.
- `<script>.bats` — тесты скрипта. Запускаются внутри контейнера
  `scripts-test:<script>` от имени root, как и сам скрипт на сервере. Рабочая
  копия репозитория монтируется в `/src` только для чтения.

Правило именования: `tests/<имя>.Dockerfile` собирается в образ
`scripts-test:<имя>`, а `tests/<имя>.bats` — его тесты.

## Как добавить тесты для нового скрипта

1. Создать `tests/<script>.Dockerfile` с `FROM` базового образа и нужными
   пакетами.
2. Создать `tests/<script>.bats`.
3. Запустить `tests/run-tests.sh <script>`.
